# v2 离线报告与版本比较口径

统一入口从批次索引、任务快照和每个 attempt 的原始记录开始。校验任务、实现、条件及实际输入身份；校验原始文件哈希、退出码、数值门槛、AB/BA 次序、重放样本和汇总字段。历史适配器继续使用 v1 的逐项复核。v2 将结果加上 task_id、attempt 位置及三种身份，旧版输出文件保留原格式。普通电脑仅需 Python 标准库。

- 严格批次中，任何所选任务失败时，整批退出非零，诊断报告列出覆盖和原因，性能表为空。全量能力巡检允许已经声明并说明原因的 unsupported 项，显示在覆盖表。目录中的未请求项标为未测。受控模型请求的时序和实际算子重放分区展示。
- 报告将未裁剪图重放时间除以每图操作次数，计算中位、样本标准差及极值。耗时图使用微秒对数轴。波动图为标准差 / 中位数，以百分比显示。两图均按实现和边界绘制，数值表保留绝对微秒、样本数和有效吞吐。仅为定义了有效工作量的 GEMM 报告 TFLOP/s，非 GEMM 可报告输出元素/s。
- 版本比较在样本产生前固定如下规则。相同 task_id、任务合同哈希、实际输入哈希、条件哈希、实现角色和操作边界才比较中位耗时。将两次运行标为“相同实现”或“实现版本变化”。计算 `(本次中位数 / 对照中位数 - 1) × 100%`，给出两个原值和实际方向。当每版本仅一轮独立进程运行时，报告“未能区分稳定变化”。图内操作和同一进程的 50 次重放均不作为独立设备复跑，分布是否重叠不用于稳定变化判定。缺任一匹配条件则展示具体原因，并省略变化率。
- 环境、任务来源、原始日志、编译器记录及产物通过每任务的证据链接定位。HTML 内嵌图形、样式与数值表，断网可阅读。若需检查记录或再次运行，把报告与结果目录一同搬移并保持相对路径，或从新位置重新生成。模型请求的首段输出与 chunk 间隔按客户端实测命名。
